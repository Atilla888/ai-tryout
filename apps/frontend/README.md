# Frontend

React app for AI Spaces — browse spaces, submit the configured form, and follow job progress on `/jobs/:id`.

From this folder:

```powershell
npm install
npm run dev
```

The dev server runs at http://localhost:5173. Point `VITE_API_URL` in the repo root `.env` at your backend (usually `http://localhost:8000`).

Lint with `npm run lint`. Build with `npm run build`.

To run the full stack including API and orchestrator, start with the root `README.md`.
